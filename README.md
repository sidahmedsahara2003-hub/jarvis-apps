# Jarvis apps

Cuatro mini apps para la pantalla de inicio del móvil: **Jarvis**, **Panel diario**, **Entreno** y **Finanzas**.

Los datos se guardan solo en el navegador de cada dispositivo (localStorage); este repositorio no contiene datos personales.

Añadir a la pantalla de inicio: iPhone → Safari → Compartir → *Añadir a pantalla de inicio*. Android → Chrome → ⋮ → *Añadir a pantalla de inicio*.
